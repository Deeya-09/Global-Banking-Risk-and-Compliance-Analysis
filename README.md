# Global-Banking-Customer-Risk-Analysis
## Overview
This project analyses a synthetic global banking customer dataset in Microsoft Excel to explore customer financial health, credit quality, KYC status and risk. 
## Dataset 
This project uses Global Banking Customer Analytics Dataset, a synthetic portfolio sourced from Kaggle. It contains key customer metrics from multiple regions. There are 1600 records and includes information related to:
### Customer Demographics
- Age
- Gender
- Country
- City
### Account Information 
- Account type
- Account Creation Date
- Last Active Date
- Account Status
- KYC Status
### Financial Information
- Account Balance
- Debt
- Annual Income
- Credit Score
### Risk Information 
- Risk Category
- Fraud Flag

Personal Identifiers were not used as analytical variables. 'Username' was primarily used as a unique customer-count field in pivot tables. 

## Tools Used 
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Excel Formulas
